## 🏃 How to Run These Projects

You can explore any of the projects by following these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ARISTOTILE-GIT/Exploratory-Data-Analysis-EDA-Projects.git](https://github.com/ARISTOTILE-GIT/Exploratory-Data-Analysis-EDA-Projects.git)
    cd Exploratory-Data-Analysis-EDA-Projects
    ```

2.  **Install the required libraries:**
    (It's highly recommended to use a virtual environment)
    ```bash
    pip install pandas numpy matplotlib seaborn jupyterlab
    ```

3.  **Run Jupyter Lab:**
    ```bash
    jupyter lab
    ```

4.  Once Jupyter Lab opens in your browser, navigate to the project notebook (`.ipynb` file) you want to view.
